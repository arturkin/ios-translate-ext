What the extension does

Translate Icelandic is a Safari extension that translates Icelandic web pages into English and lets you look up individual Icelandic words. Select a word or phrase to see an instant gloss, a link to the Glosbe bilingual dictionary, and — on request — the full BÍN inflection table for the word.

Getting started

On Mac (Safari)

  1. Open Safari → Settings → Extensions.
  2. Turn on Translate Icelandic.
  3. Click Edit Websites (or the extension's button in the toolbar) and choose Allow — set it to Always Allow on Every Website for the smoothest experience.

On iPhone / iPad (Safari)

  1. Open Settings → Apps → Safari → Extensions.
  2. Tap Translate Icelandic and turn it on.
  3. Tap All Websites → Allow so it can work on the sites you visit.

How to use it

  • Translate a whole page: on an Icelandic page a floating 🇮🇸 button appears — tap it to translate the visible text to English.
  • Look up a word: select a word or phrase. A small “Look up” chip appears next to your selection; tap it to open the look-up panel with the English gloss.
  • See more: the panel links to the Glosbe dictionary (opens in a new tab) and has a “Show inflection table” button for the full BÍN paradigm of the word.

Frequently asked questions

I don't see the extension — where is it?

Make sure it's enabled and allowed to run on the current site (see Getting started above). On Mac, the extension's button lives in the Safari toolbar; if it's hidden, choose View → Customize Toolbar and drag it in.

Translation isn't working / nothing happens.

The extension only activates on pages it detects as Icelandic, and it needs permission to run on that website. Confirm the site is allowed, then reload the page. A working internet connection is required, since translation is done by an online service.

The 🇮🇸 button doesn't appear on a page.

The page may not be detected as Icelandic (the detector is intentionally conservative so it won't trigger on English pages). You can still look up individual words by selecting text, and you can force the look-up feature on via the extension's popup toggle.

Is my browsing or data collected?

No. The extension has no analytics, accounts, or tracking. It sends only the specific text you ask it to translate or look up, and only to the translation/dictionary providers needed to return a result. Full details are in the Privacy Policy.

How do I report a bug or request a feature?

Email artur@travelshift.com with what you expected, what happened, and the page you were on. Screenshots help.
